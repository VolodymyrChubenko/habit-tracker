# Challenge Tracker — дизайн

| Папка | Що там |
|---|---|
| `default/` | Основний дизайн (палітра «М'ята»): екрани, розміри, токени поточних тем. Опис — `default/README.md` |
| `default/screens/` | Усі екрани (`*.dc.html`). Кожен основний екран має пропи `theme` (light/dark) і `palette` |
| `matcha/`, `crimson/`, `gallery/`, `frost/`, `dune/` | Нові палітри: `README.md` з токенами й контрастом + `_light_<name>.scss` / `_dark_<name>.scss` |
| `palettes.json` | Усі токени всіх палітр у JSON (джерело для SCSS і для дизайну) |
| `canvas.json` | Розкладка канвасу Claude Design (сторінки «Основний дизайн» і «Нові палітри») |

## Палітри

| Ключ | Назва | Референс |
|---|---|---|
| `default` | М'ята | поточні `src/styles/themes/_light.scss`, `_dark.scss` |
| `matcha` | Матча | `tracker/1.jpg` |
| `crimson` | Кармін | `tracker/2.jpg` |
| `gallery` | Галерея | `tracker/3.jpg` |
| `frost` | Іній | `tracker/4.jpg` |
| `dune` | Дюна | `tracker/5.jpg` |

Правила:

- Змінюються лише значення CSS-змінних — імена ті самі, що в поточних темах; компоненти не чіпаються.
- Кожна палітра має світлу й темну тему. Палітра й тема обираються незалежно (`data-palette` + `data-theme` на `<html>`).
- Кольори челенджів (ColorPicker PRESETS) не залежать від палітри.
- Нові палітри перевірені на контраст WCAG AA (≥ 4.5:1 для тексту, підписів, кнопок і акценту як тексту). «М'ята» лишається як є.

## Налаштування → блок «Палітра»

Новий блок між «Нагадування» і «Зовнішній вигляд» (див. `default/screens/Settings.dc.html`):
сітка 3×2 карток, у кожній — фон палітри (у поточній темі) з трьома кольорами-референсами й назва;
вибрана картка — рамка 2px `--color-accent`, назва 600. `role="radiogroup"` / `role="radio"`.
- `TASK-accent-48B194.md` — заміна акценту М'яти на #48B194 (лише значення токенів).
