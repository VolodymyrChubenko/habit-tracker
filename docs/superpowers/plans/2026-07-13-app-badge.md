# App Icon Badge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Числовий бейдж на іконці встановленої PWA = кількість непрочитаних push-нагадувань; скидається при відкритті застосунку або кліку по сповіщенню.

**Architecture:** Джерело істини — активні сповіщення (`registration.getNotifications()`), жодного окремого стану. Хелпери в `src/utils/badgeUtils.ts` викликаються з двох місць: service worker (після показу сповіщення та по кліку) і вікно застосунку (при відкритті/фокусі — закрити сповіщення + очистити бейдж).

**Tech Stack:** App Badging API (`navigator.setAppBadge`/`clearAppBadge`), service worker (injectManifest/Workbox), React hook, Vitest.

**Spec:** `docs/superpowers/specs/2026-07-13-app-badge-design.md`

## Global Constraints

- TypeScript strict; проєкт збирається `npm run build` (tsc + vite).
- Серверний код (`api/*`) не змінюється.
- Усі виклики Badging API — fire-and-forget: помилка ніколи не ламає показ сповіщення чи роботу застосунку (мовчазний `catch`).
- Feature detection: без `setAppBadge` у navigator — no-op (Android/Firefox поводяться як сьогодні).
- Коментарі в коді — українською, у стилі наявних файлів.

```typescript
// src/utils/badgeUtils.ts

/** Мінімальний зріз Notification — достатній і для тестів, і для DOM-типу. */
export interface ReminderNotification {
  tag: string;
  close(): void;
}

/** Структурно сумісний із ServiceWorkerRegistration (вікно і SW). */
export interface NotificationSource {
  getNotifications(): Promise<ReminderNotification[]>;
}

/** Badging API відсутній у lib.dom для WorkerNavigator — типізуємо вручну. */
interface BadgeCapableNavigator {
  setAppBadge?: (count?: number) => Promise<void>;
  clearAppBadge?: () => Promise<void>;
}

const badgeNav = (): BadgeCapableNavigator =>
  (globalThis.navigator ?? {}) as BadgeCapableNavigator;

/**
 * Бейдж = кількість активних сповіщень. excludeTag виключає щойно
 * клікнуте сповіщення: після close() воно ще може бути в списку (race).
 * Fire-and-forget: будь-яка помилка мовчазно ігнорується.
 */
export const syncBadge = async (
  reg: NotificationSource,
  excludeTag?: string,
): Promise<void> => {
  const nav = badgeNav();
  if (!nav.setAppBadge || !nav.clearAppBadge) return;
  try {
    const notifications = await reg.getNotifications();
    const count = notifications.filter(n => n.tag !== excludeTag).length;
    if (count > 0) await nav.setAppBadge(count);
    else await nav.clearAppBadge();
  } catch {
    // Badging API не критичний — сповіщення важливіші за лічильник
  }
};

/** Відкриття застосунку = «прочитано»: закрити reminder-сповіщення, скинути бейдж. */
export const clearReminders = async (reg: NotificationSource): Promise<void> => {
  try {
    const notifications = await reg.getNotifications();
    for (const n of notifications) {
      if (n.tag.startsWith('reminder')) n.close();
    }
  } catch {
    // без сповіщень все одно чистимо бейдж нижче
  }
  try {
    await badgeNav().clearAppBadge?.();
  } catch {
    // мовчазний no-op
  }
};
```

- [ ] **Step 1: Update `src/sw.ts`**

Повний новий вміст файлу (зміни: імпорт `syncBadge`; `.then(() => syncBadge(...))` у push; `Promise.all` із перерахунком у notificationclick):

```typescript
/// <reference lib="WebWorker" />
/// <reference types="vite-plugin-pwa/client" />
import { precacheAndRoute } from 'workbox-precaching';
import { syncBadge } from './utils/badgeUtils';

declare const self: ServiceWorkerGlobalScope;

precacheAndRoute(self.__WB_MANIFEST);

interface PushPayload {
  title?: string;
  body?: string;
  challengeId?: string;
}

self.addEventListener('push', event => {
  let data: PushPayload = {};
  try {
    data = (event.data?.json() as PushPayload) ?? {};
  } catch {
    // не-JSON payload — покажемо дефолтний текст
  }

  event.waitUntil(
    self.registration
      .showNotification(data.title ?? 'Challenge Tracker', {
        body: data.body ?? 'Час відмічати челенджі! 🌿',
        icon: '/icon-192.png',
        badge: '/icon-192.png',
        tag: data.challengeId ? `reminder-${data.challengeId}` : 'reminder',
        data: { url: '/' },
      })
      // бейдж на іконці = кількість активних нагадувань
      .then(() => syncBadge(self.registration)),
  );
});

self.addEventListener('notificationclick', event => {
  event.notification.close();
  // close() асинхронний у списку сповіщень — виключаємо клікнутий tag явно
  const clickedTag = event.notification.tag;
  event.waitUntil(
    Promise.all([
      syncBadge(self.registration, clickedTag),
      self.clients.matchAll({ type: 'window', includeUncontrolled: true }).then(clients => {
        const existing = clients.find(c => 'focus' in c);
        if (existing) return existing.focus();
        return self.clients.openWindow('/');
      }),
    ]),
  );
});
```

```typescript
// src/hooks/useAppBadge.ts
import { useEffect } from 'react';
import { clearReminders } from '../utils/badgeUtils';

/**
 * Відкриття/повернення в застосунок = «нагадування прочитані»:
 * закриває активні reminder-сповіщення і скидає бейдж на іконці.
 * Монтується один раз в App.
 */
export function useAppBadge() {
  useEffect(() => {
    const clear = async () => {
      if (!('serviceWorker' in navigator)) return;
      const reg = await navigator.serviceWorker.getRegistration();
      if (reg) await clearReminders(reg);
    };

    void clear();

    const onVisible = () => {
      if (document.visibilityState === 'visible') void clear();
    };
    document.addEventListener('visibilitychange', onVisible);
    return () => document.removeEventListener('visibilitychange', onVisible);
  }, []);
}
```

## Manual Verification (після деплою)

1. iPhone (iOS 16.4+, PWA на домашньому екрані, дозвіл на сповіщення): дочекатися двох нагадувань різних челенджів → бейдж «2».
2. Клік по одному сповіщенню → застосунок відкривається, бейдж зникає (відкриття = все прочитано).
3. Знову дочекатися нагадування, не відкривати сповіщення, відкрити застосунок з іконки → бейдж зникає, сповіщення прибрані зі шторки.
4. Android: сповіщення показуються як раніше; крапка на іконці — за поведінкою лаунчера, без числа.
